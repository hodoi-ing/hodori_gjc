# 📐 HWP 템플릿(양식) 제작 표준 프로토콜

> **[목적]**
> AI 에이전트(GJC)가 HWP/HWPX 문서를 에러 없이 완벽하게 자동화(데이터 치환, 표 수정)하기 위해서는, 원본이 되는 템플릿 파일이 **반드시 정해진 규격**대로 작성되어야 합니다.
> 본 문서는 사람이 템플릿을 만들 때 지켜야 할 절대 규칙입니다.

---

## 1. 📝 텍스트 치환 규칙 (누름틀 사용)

에이전트가 텍스트를 끼워 넣을 위치를 찾기 위해 단순 기호(`{{이름}}`) 대신, 한글 프로그램의 고유 기능인 **[누름틀(Field)]**을 사용합니다.

*   **누름틀 삽입 방법:** 한글 앱에서 `입력` > `누름틀` (단축키 `Ctrl+K, E`)
*   **네이밍 컨벤션:** 
    *   누름틀 이름은 **반드시 영문 소문자와 스네이크 케이스(`_`)**만 사용합니다.
    *   ❌ 잘못된 예: `이름`, `ReportDate`, `날짜-1`
    *   ✅ 올바른 예: `user_name`, `report_date`, `total_amount`
*   **이유:** XML 파싱(`hwpx-kit`) 시 인코딩 문제나 띄어쓰기 에러를 원천 차단하기 위함입니다.

## 2. 📊 표(Table) 제작 규칙

HWP의 표 구조는 엑셀과 달리 셀 병합이 매우 파편화되어 있습니다. 에이전트가 표에 데이터를 동적으로 추가할 때 구조가 깨지지 않게 하려면 다음을 지킵니다.

*   **표 이름 지정 필수:** 표 속성에서 **'표 이름'**을 반드시 영문으로 지정합니다. (예: `sales_table`)
    *   이름이 없으면 에이전트가 5개의 표 중 어디에 데이터를 넣어야 할지 찾지 못합니다.
*   **데이터 추가 행(Row) 병합 금지:**
    *   헤더(제목 줄)는 셀 병합을 자유롭게 해도 됩니다.
    *   하지만 **데이터가 동적으로 추가될 아래쪽 행(Row)들은 절대 셀을 세로로 병합하지 마십시오.** 에이전트가 `add_table_row` 호출 시 배열이 어긋납니다.
*   **고정 서식 적용:** 
    *   새로 추가되는 데이터가 템플릿의 글꼴과 정렬을 따라갈 수 있도록, 첫 번째 데이터 입력 줄에 미리 글꼴/가운데 정렬 등의 서식을 세팅해 둡니다.

## 3. 💾 파일 저장 확장자

*   템플릿 파일은 가급적 **`.hwpx` (HWPX 문서)**로 저장합니다. 
*   구버전 `.hwp`는 윈도우 OLE(`pyhwpx`) 환경에서만 수정이 가능하지만, `.hwpx`는 리눅스 서버나 맥북에서도 XML 조작(`python-hwpx-automation`)을 통해 가벼운 텍스트 치환이 가능하기 때문입니다.
