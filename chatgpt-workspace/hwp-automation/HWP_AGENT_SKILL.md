# 🧙‍♂️ HWP Master Agent Skill (GJC 전용 자동화 지침서)

> **[목적]**
> 본 문서는 GJC(Gajae Code) 및 챗GPT 등 AI 에이전트가 사용자의 HWP/HWPX 문서 처리 요청(읽기, 수정, 생성)을 받았을 때, **어떤 도구를 선택하고 어떻게 스크립트를 작성해야 하는지** 규정하는 절대 지침서다.

---

## 1. 🛠️ 상황별 도구 선택 라우팅 (Tool Routing)

에이전트는 사용자의 지시를 분석하여 아래 기준에 따라 **백그라운드에서 실행할 파이썬 라이브러리**를 결정한다.

*   **A. [읽기 / 분석 / 요약]** (예: "이 보고서 읽고 요약해 줘", "매출 데이터 추출해 줘")
    *   👉 **사용 툴:** `syhwp` (또는 `python-hwpx-automation`의 추출 모듈)
    *   **이유:** 무거운 한글 프로그램을 띄우지 않고, 텍스트와 표 데이터를 마크다운(Markdown)으로 가장 빠르게 추출(RAG)하기 위함.
*   **B. [단순 텍스트 수정 / 양식 채우기]** (예: "이 양식 빈칸에 이름이랑 날짜 채워줘")
    *   👉 **사용 툴:** `python-hwpx-automation` / `hwpx-kit`
    *   **이유:** OS 상관없이 XML 기반으로 빠르게 텍스트 및 누름틀(필드) 데이터만 치환 가능.
*   **C. [표 수정 / 복잡한 서식 변경]** (예: "표에 행 추가해", "셀 병합해", "빨간색으로 칠해")
    *   👉 **사용 툴:** `pyhwpx` (Win32 OLE 자동화)
    *   **이유:** XML로 표 구조를 직접 건드리면 파일이 손상될 확률이 매우 높음. 반드시 로컬 한글(hwp.exe) 앱을 띄워 OLE로 조작해야 완벽한 표 수정 및 서식 변경이 가능.

---

## 2. ⚡ 에이전트 실행 프로토콜 (Execution Protocol)

에이전트는 사용자의 자연어 요청을 받으면 다음 순서로 작업을 처리한다.

1.  **의도 파악:** 사용자가 원하는 작업이 A, B, C 중 어디에 해당하는지 판단.
2.  **스크립트 자동 작성:** 에이전트는 바이너리 HWP 파일을 직접 뜯어보려 시도하지 말고, 즉시 `/tmp/hwp_task.py` 같은 임시 파이썬 스크립트를 작성한다. (선택된 라이브러리를 import 하는 코드 작성)
3.  **코드 실행:** `bash` 툴을 사용해 `python /tmp/hwp_task.py`를 실행한다.
4.  **결과 보고:** 코드가 성공적으로 실행되었는지 확인 후, 사용자에게 자연어로 결과를 보고한다.

---

## 3. 🛡️ 필수 안전 수칙 (Safety Rules)

- **원본 보존의 원칙:** 어떠한 수정 작업(B, C)을 하더라도 **절대로 원본 파일을 덮어쓰지 마라.** 반드시 파일명 끝에 `_수정본.hwp` (또는 `.hwpx`)를 붙여서 새로 저장(Save As)한다.
- **IM_NOT_AI 연계:** 결과 보고 시 로봇처럼 "수정이 완료되었습니다"라고 하지 마라. 최상위 규칙인 `IM_NOT_AI.md`에 따라 "표에 한 줄 추가하고 노란색 칠해서 `_수정본.hwp`로 빼뒀습니다. 확인해 보시죠." 같이 전문가스러운 자연스러운 어투를 사용한다.
