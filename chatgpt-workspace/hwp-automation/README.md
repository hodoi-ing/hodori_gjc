# 📄 HWP 자동화 프로젝트

> AI가 HWP/HWPX 문서 작업을 직접 수행할 수 있을까?

`chatgpt-workspace`에서 도리보고와 별도로 진행하는 작은 실험 프로젝트다.

현재 목표는 HWP 자동화를 처음부터 전부 새로 만드는 것이 아니다. GitHub에 이미 공개된 좋은 프로젝트들의 장점을 조사하고, 필요한 기능만 조합해 **AI Agent가 실제 문서 작업을 수행할 수 있는 구조**를 만드는 것이다.

---

## 🎯 목표

```text
사용자 요청
   ↓
AI Agent / GJC
   ↓
문서 구조 파악
   ↓
필요한 도구 선택
   ↓
HWP/HWPX 읽기 · 생성 · 수정
   ↓
검증
   ↓
완성 문서
```

우선 작은 기능부터 검증한다.

1. HWP/HWPX 내용 읽기
2. HWPX 문서 생성
3. 기존 양식에 데이터 입력
4. 표·텍스트·서식 수정
5. 결과 검증
6. AI Agent가 자연어 명령으로 작업 수행

---

## 🧩 참고할 GitHub 소스

### `airmang/python-hwpx-automation`

HWPX 자체를 Python으로 생성·편집·검증하는 자동화 엔진 후보.

**가져올 장점**
- HWPX 문서 생성·편집
- 검색·치환
- 표와 서식 처리
- 문서 검증
- CLI / MCP 기반 Agent 연결 구조

### `6aneffy/hwpx-kit`

HWPX 자동화 기능을 AI Agent가 사용하기 쉽게 구성한 프로젝트.

**가져올 장점**
- Agent용 작업 단위 설계
- CLI 기반 문서 작업
- 양식 작성·메일머지·표 생성 등 실사용 사례
- 원본 보존과 서식 유지에 대한 접근

### `sysphere/syhwp`

HWP/HWPX 문서에서 텍스트·표 등의 내용을 추출하는 후보.

**가져올 장점**
- 기존 문서 읽기
- AI 분석/RAG 입력용 데이터 추출
- Markdown/HTML 등으로 변환

### `martiniifun/pyhwpx`

Windows에 설치된 한/글 프로그램을 Python으로 직접 제어하는 후보.

**가져올 장점**
- 실제 한/글 프로그램 자동 조작
- HwpAutomation API 활용
- 파일 수준 자동화로 해결하기 어려운 작업의 보조 수단

## 🏗️ 생각 중인 구조

모든 소스를 그대로 합치는 방식은 사용하지 않는다.

```text
                 🤖 AI Agent / GJC
                        │
                 HWP 자동화 인터페이스
                        │
          ┌─────────────┼─────────────┐
          ↓             ↓             ↓
       문서 읽기      문서 편집      한/글 조작
          │             │             │
        syhwp       python-hwpx       pyhwpx
                        │
                  hwpx-kit 참고
                        │
                        ↓
                   결과 검증
                        ↓
                    HWPX 출력
```

핵심은 **각 프로젝트의 장점을 가져오되 우리 프로젝트의 인터페이스는 독립적으로 유지하는 것**이다.

특정 오픈소스 하나에 전체 구조를 종속시키지 않는다.

---

## 🧪 개발 원칙

- 처음부터 거대한 HWP Agent를 만들지 않는다.
- 작은 기능 하나를 구현하고 실제 HWPX 샘플로 검증한다.
- 기존 오픈소스를 먼저 조사하고, 필요한 부분만 구현한다.
- 원본 문서를 함부로 덮어쓰지 않는다.
- 생성된 문서는 구조와 내용이 정상인지 다시 검사한다.
- 오픈소스 코드를 가져올 때는 각 저장소의 라이선스와 재배포 조건을 확인한다.
- `ONTOLOGY.md`, `PROTOCOL.md`, `IM_NOT_AI.md` 등 저장소의 상위 운영 규칙을 따른다.

## 🚧 현재 단계

**아이디어 / 기술조사 단계**

아직 실제 자동화 엔진을 구현하지 않는다.

먼저 참고 소스들의 기능과 라이선스를 비교하고, **가장 작은 HWPX 읽기 → 생성 → 수정 실험**부터 시작한다.

최종적으로는 다음과 같은 사용 경험을 목표로 한다.

> "이 양식에 이 자료를 넣고 완성된 HWPX 문서를 만들어줘."
>
> → Agent가 문서를 분석하고 필요한 도구를 선택한다.
> → 작업을 수행한다.
> → 결과를 검증한다.
> → 완성된 문서를 돌려준다.
