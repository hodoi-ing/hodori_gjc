# 📄 HWP 자동화 프로젝트

> AI가 HWP/HWPX 문서 작업을 직접 수행할 수 있을까?

`chatgpt-workspace`에서 도리보고와 별도로 진행하는 핵심 파이프라인 프로젝트다.

현재 목표는 HWP 파서를 처음부터 전부 새로 만드는 것이 아니다. GitHub에 이미 검증된 최상위 오픈소스들의 장점만 조합해 **AI Agent(GJC)가 실제 문서 작업을 수행할 수 있는 '만능 리모컨(Interface)' 구조**를 구축하는 것이다.

---

## 🎯 목표 흐름도

```text
🗣️ 사용자 요청 ("이 양식 빈칸 채우고 표에 한 줄 추가해 줘")
   ↓
🤖 AI Agent / GJC (의도 파악 및 도구 라우팅)
   ↓
🛠️ 필요한 도구 선택 (읽기 / 텍스트 수정 / 표 구조 조작)
   ↓
📄 임시 Python 스크립트 작성 및 실행
   ↓
✅ 원본 보존 및 검증 (_수정본.hwp 생성)
   ↓
🎉 완성 문서 반환 (IM_NOT_AI 톤앤매너 보고)
```

우선 작은 기능부터 검증한다.
1. HWP/HWPX 내용 읽기 (RAG 데이터화)
2. HWPX 문서 생성 및 기존 양식 데이터 입력
3. 표·텍스트·서식의 복잡한 구조 수정
4. AI Agent가 자연어 명령만으로 위 작업을 백그라운드에서 수행

---

## 🧩 핵심 무기 (4대장 오픈소스) 및 라우팅 전략

하나의 오픈소스에 종속되지 않는다. 표 수정과 텍스트 추출 등 각 작업의 난이도와 특성에 맞춰 GJC가 무기를 바꿔 든다.

### 1. `sysphere/syhwp` (읽기 전용 돋보기)
- **역할:** HWP/HWPX 내용 초고속 추출 및 AI 분석(RAG) 입력
- **특징:** 가장 가볍고 빠름. 수정 기능이 없는 순수 Parser.

### 2. `airmang/python-hwpx-automation` & `6aneffy/hwpx-kit` (XML 조작 래퍼)
- **역할:** OS(리눅스/맥/클라우드) 상관없이 HWPX 생성 및 단순 텍스트/누름틀 채우기
- **특징:** 가볍지만, 새로운 표를 생성하거나 셀 구조(XML)를 직접 변경할 경우 포맷이 깨질 위험이 있음.

### 3. `martiniifun/pyhwpx` (로컬 완벽 제어 - Win32 OLE)
- **역할:** 복잡한 표 구조 수정, 셀 병합, 서식/색상 변경 등 완벽한 조작
- **특징:** 실제 윈도우 한글(hwp.exe) 프로그램을 백그라운드에서 조종하므로 사람이 하는 모든 작업 가능. 단, 윈도우 환경 제약 있음.

## 🏗️ 확정된 아키텍처

```text
                 🤖 AI Agent / GJC
                        │ (자연어 명령 해석)
                 HWP 자동화 인터페이스 (HWP_AGENT_SKILL.md)
                        │
          ┌─────────────┼─────────────┐
          ↓             ↓             ↓
      [읽기/추출]    [단순 텍스트]    [표/복잡한 서식]
          │             │             │
        syhwp       hwpx-kit       pyhwpx
                        │
                        ↓
             원본 보존 및 _수정본.hwp 출력
```

핵심은 **각 프로젝트의 장점을 가져오되, GJC가 이를 자유롭게 호출할 수 있도록 브릿지(Skill)를 두는 것**이다.

---

## 🧪 개발 및 운영 원칙

- **원본 절대 보존:** 원본 문서를 함부로 덮어쓰지 않고 항상 복사본(`_수정본`)으로 작업한다.
- **IM_NOT_AI 적용:** 에이전트가 결과를 보고할 때 로봇처럼 굴지 않고, 실제 비서처럼 전문가적 통찰과 함께 자연스럽게 보고한다.
- `ONTOLOGY.md`, `PROTOCOL.md` 등 저장소의 상위 운영 규칙을 따른다.

**1. 아키텍처 설계 및 에이전트 지침서 세팅 완료 (✅ 완료)**

- GJC가 이 툴들을 어떻게 써야 하는지 규정한 뇌(Brain) 역할의 문서 `HWP_AGENT_SKILL.md` 세팅 완료.

**2. 넥스트 액션 (진행 중)**
- GJC가 실제로 파이썬 코드 없이 자연어로 문서를 조작할 수 있도록, 위 4대장을 하나로 감싼 **[통합 Python Wrapper 클래스]** 뼈대 코드 작성.
- 가장 작은 실험인 `샘플 HWPX 읽기 → 표에 행 추가 → 저장` 파이프라인 테스트.
