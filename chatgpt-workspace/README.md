# 💬 ChatGPT 전용 작업 공간 (chatgpt-workspace)

이 폴더는 **ChatGPT**와 호도리가 아이디어를 작성하거나, 신규 코드를 생성하고, 리서치 및 문서 자동화 엔진을 연구/개발하기 위한 전용 공간입니다.

## 📂 서브 프로젝트 및 폴더 구조
- `doribogo/`: **[v3.0.0]** 범용 실시간 시그널 수집기 & SNS 6장 슬라이드 카드뉴스 엔진 (`universal_harvester.py`, `CARD_FORMAT.md`, `RADAR.md`)
- `hwp-automation/`: HWP/HWPX 반자동화 엔진 (`hwp_bridge.py`, `batch_processor.py`, 승인 게이트)
- `ideas_and_plans/`: 프로젝트 기획서, 구조 설계서, 아이디어 노트
- `generated_code/`: 신규 생성 코드 및 모듈

## 📌 작업 규칙
1. 최상위 `PROTOCOL.md`, `ONTOLOGY.md`, `IM_NOT_AI.md` 수칙을 준수하여 작성한다.
2. `gjc-workspace/` 내부 파일과의 충돌을 피하기 위해 본 폴더 내부에서 1차 작성/수정을 진행한다.
