# 💬 ChatGPT 전용 작업 공간 (chatgpt-workspace)

이 폴더는 **ChatGPT**가 웹 브라우저에서 아이디어를 작성하거나, 신규 코드를 생성하고, 리팩토링 및 기획서를 업로드하기 위한 전용 공간입니다.

## 📂 서브 폴더 구조
- `ideas_and_plans/`: ChatGPT가 작성한 프로젝트 기획서, 구조 설계서, 아이디어 노트
- `generated_code/`: ChatGPT가 작성한 신규 코드 및 모듈

## 📌 작업 규칙
1. 최상위 `PROTOCOL.md`, `ONTOLOGY.md`, `IM_NOT_AI.md` 수칙을 준수하여 작성한다.
2. `gjc-workspace/` 내부 파일과의 충돌을 피하기 위해 본 폴더 내부에서 1차 작성/수정을 진행한다.
