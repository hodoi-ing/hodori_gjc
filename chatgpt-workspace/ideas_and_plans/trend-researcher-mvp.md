# AI Trend Researcher — 1차 실험

## 목적
X, Threads, Reddit, GitHub에서 발견한 AI 관련 정보를 한곳에 모은 뒤, 같은 주제끼리 묶고 실제 프로젝트로 이어지는 신호를 빠르게 확인한다.

## 이번 실험의 범위
- 웹/API 자동 수집은 아직 넣지 않는다.
- 먼저 수집된 게시물/프로젝트 데이터를 JSON으로 넣어 분석한다.
- 외부 API 키와 로그인 정보는 저장하지 않는다.
- 결과는 Markdown 보고서로 출력한다.

## 데이터 흐름
1. X / Threads / Reddit / GitHub에서 자료 발견
2. `posts.json` 형태로 입력
3. 키워드 기반으로 주제 분류
4. 출처별 언급량과 GitHub 프로젝트 신호 계산
5. Markdown 보고서 생성

## 다음 검증
실제 20~50개 정도의 자료를 넣어서 분류 품질과 중복 문제를 확인한다.
그 결과가 쓸 만하면 그때 웹 검색/API 연동을 검토한다.

## 판단 기준
- 실제 데이터와 추정을 분리한다.
- 숫자는 입력 데이터에서 계산된 값만 사용한다.
- 자동 수집보다 먼저 작은 실험으로 가치가 있는지 확인한다.
