# AI 돋보기 — 카드뉴스형 AI 생태계 조사 MVP

## 프로젝트 이름
**AI 돋보기**

AI 생태계에서 일어나는 흐름을 여러 커뮤니티와 실제 프로젝트를 통해 들여다보고, 중요한 움직임을 카드뉴스형 텍스트로 보여준다.

## 목적
X, Threads, Reddit, GitHub와 한국 커뮤니티/서비스에서 발견한 AI 관련 정보를 모아 같은 이슈끼리 묶고, 출처별 반응을 비교해 읽기 쉬운 카드뉴스형 리포트로 보여준다.

## 사용 방식
사용자가 조사할 주제와 원하는 카드 수를 지정한다.

예:
- `오늘 AI Agent 이슈 5개`
- `이번 주 AI 개발 트렌드 10개`
- `한국에서 AI로 만들고 있는 것 7개`
- `Codex 관련 실제 프로젝트 5개`

지정한 개수만큼 핵심 이슈를 선정한다. 카드 개수는 고정하지 않는다.

## 검색 소스
기본 후보 소스는 다음 10곳이다.

### 글로벌
1. X
2. Threads
3. Reddit
4. GitHub

### 한국
5. GeekNews
6. OKKY
7. GPTers
8. 디스콰이엇
9. Velog
10. AI Hub

주제에 따라 모든 소스를 기계적으로 검색하지 않고 관련성이 높은 소스를 우선 사용한다. 필요하면 뉴스, 논문, 공식 문서 등 추가 출처로 교차검증한다.

## 핵심 조사 방식
단순히 사이트별 결과를 나열하지 않는다.

1. 여러 소스에서 관련 자료를 찾는다.
2. 같은 사건/주제/흐름을 하나의 이슈로 묶는다.
3. 이슈가 발견된 소스를 표시한다.
4. 각 커뮤니티의 반응을 비교한다.
5. 실제 프로젝트/사용 사례가 있는지 확인한다.
6. 사실, 작성자의 주장, AI의 해석을 분리한다.
7. 신호 강도를 평가한다.
8. 호도리에게 어떤 의미가 있는지 정리한다.

## 카드 구성
각 카드는 다음 순서를 기본으로 한다.

1. `CARD NN` + 제목
2. 한 줄 요약
3. 무엇이 일어나고 있는지
4. 어디에서 발견됐는지 + 발견된 소스 수
5. 소스별 반응 요약
6. 작성자(가능한 경우 핸들/ID 포함)
7. 원문 URL
8. 사실 / 작성자 주장 / AI 해석 구분
9. 실제 프로젝트·사용 사례
10. 반응 및 신호 강도
11. 호도리에게 어떤 의미가 있는지

## 반응 분석
관련 이슈에 대한 반응을 다음처럼 구분한다.

- 긍정
- 중립/관심
- 부정/비판
- 실제 사용 경험
- 실제 프로젝트/구현

단순 언급량만으로 신호 강도를 결정하지 않는다. 여러 독립 출처에서 반복되는지, 실제 사용/프로젝트로 이어졌는지 등을 함께 본다.

## 결과 형식
이미지 파일을 생성하지 않는다. Markdown/텍스트로 카드뉴스처럼 읽히도록 구성한다.

예시:

```text
# 🛰️ AI 돋보기
2026-08-25 · AI 개발

## 🟦 CARD 01
### AI Agent가 개발환경을 직접 다루기 시작했다

한 줄 요약
> ...

무슨 일이야?
> ...

🌐 발견된 곳: X · Reddit · GitHub · GeekNews · OKKY (5곳)

💬 커뮤니티 반응
🗣️ X — 작성자: @example
> ...

🔴 Reddit — 작성자: u/example
> ...

🇰🇷 OKKY — 작성자: example
> ...

🧑‍💻 GitHub — 작성자: example/project
> 실제 프로젝트 확인

📌 사실
> ...

🗣️ 작성자 주장
> ...

🤖 AI 해석
> ...

🔥 신호: 매우 강함

🎯 호도리에게
> ...
```

## 데이터 저장 원칙
- GitHub에는 코드, 설계, 규칙만 저장한다.
- 검색할 때마다 원문 데이터를 GitHub에 누적하지 않는다.
- 이미지/스크린샷/원문 대량 저장을 하지 않는다.
- 조사 결과는 기본적으로 대화에서 보여주며, 장기 보관이 필요할 때만 별도 저장을 검토한다.

## MVP 단계
- 웹/API 자동 수집은 아직 넣지 않는다.
- ChatGPT가 실제 웹 검색으로 자료를 찾고 카드 형식으로 정리하는 방식을 먼저 검증한다.
- 여러 번 사용한 뒤 필요한 필드와 평가 기준을 확정한다.
- 그 다음 자동 수집/API 연동 여부를 결정한다.
