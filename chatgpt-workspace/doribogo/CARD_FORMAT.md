# 🐯 도리보고 2.0 인텔리전스 브리핑 포맷 (Card Format)

> **[AI 프롬프트 지침]**
> 도리보고 검색 결과를 반환할 때, 반드시 아래의 마크다운 템플릿 구조를 엄격하게 지켜서 출력할 것.
> 단순 요약을 절대 지양하고, 현상 이면의 '시그널 디코딩'과 '숨겨진 맥락(Hidden Context)'을 도출하라.

---

## 📋 출력 템플릿

```markdown
# 📡 [DRI/DRT-키워드] 타이틀 (어그로성 제목 X, 핵심을 찌르는 제목)

> 💡 **핵심 인사이트 (BLUF - Bottom Line Up Front)**
> [이슈의 본질을 꿰뚫는 1~2줄 요약. 단순 사실 전달이 아닌, "왜 이 현상이 지금 중요한지" 명시할 것]

| 🏷 노션 자동화 매핑 | 📊 지표 평가 (AI 판단) |
| :--- | :--- |
| **분류:** [IT/부동산/경제/게임 등] | **중요도:** [🔴높음 / 🟡중간 / 🟢낮음] (선정 이유 10자 내외) |
| **관련항목:** [수익시스템, 시장, 경쟁, 자동화 등] | **위험도:** [🔴높음 / 🟡중간 / 🟢낮음] (리스크 요인 짧게) |
| **데이터구분:** [팩트 / 여론 / 혼합] | **의사결정:** [수집 완료 → 노션 초안 전환 대기] |

<br/>

### 1. 🔍 시그널 디코딩 (현상 이면의 분석)
* **📰 표면적 팩트:** 
  * [단순 발생한 사건, 기사 내용 등 표면적 팩트 1~2줄]
* **🗣️ 대중의 반응 (커뮤니티/SNS):** 
  * [레딧, X(트위터), 커뮤니티 등에서의 실제 유저 반응이나 트래픽 동향]
  * [예: "공식 기사는 긍정적이나, 커뮤니티에서는 가격 정책에 대한 비판이 압도적임"]
* **🕵️‍♂️ 숨겨진 맥락 (Hidden Context):**
  * [이 사건이 의도하는 바, 혹은 향후 시장/수익 모델에 미칠 진짜 영향력 분석]
  * [예: "경쟁사의 부정적 이슈를 덮기 위해 의도적으로 타이밍을 맞춘 유출로 보임"]

### 2. 🧱 원문 데이터 (보존)
* **출처:** [소스 링크 1](#) | [소스 링크 2](#)
* **핵심 인용:** _"[원문에서 가장 중요한 문장 1개를 왜곡 없이 그대로 발췌]"_

### 3. ⚡ 넥스트 액션 (행동 지침)
- [ ] **온톨로지 업데이트:** [노션 마스터 DB에 새롭게 추가해야 할 패턴이나 항목 제안]
- [ ] **추적 및 모니터링:** [이후 지속적으로 모니터링해야 할 지표나 관련 기업/키워드]
- [ ] **HWP 자동화 연계 (선택):** [이 이슈를 바탕으로 문서화(보고서 등)가 필요한 경우 제안]
```
