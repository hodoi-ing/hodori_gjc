# 🐯 도리보고 2.0: 콘텐츠 자동화 리서치 포맷 (Content Research Card)

> **[AI 프롬프트 지침]**
> 도리보고는 '글쓰기 및 카드뉴스 자동화'를 위한 리서치 엔진이다.
> 검색 결과를 반환할 때, 작성자가 즉시 블로그 포스팅이나 카드뉴스로 가공할 수 있도록 '글쓰기 재료(팩트, 여론, 깃허브 소스 등)'를 아래 템플릿에 맞춰 엄격하게 구조화하라.

---

## 📋 출력 템플릿

```markdown
# 📡 [리서치 주제] 타이틀 (글의 가제가 될 수 있는 매력적인 제목)

> 💡 **핵심 훅 (The Hook)**
> [독자의 시선을 확 끌 수 있는 한 줄 요약 / 카드뉴스 1장짜리 메인 카피로 쓸 만한 문장]

| 🎯 콘텐츠 방향성 | 📊 타겟 독자 반응 (AI 판단) |
| :--- | :--- |
| **추천 포맷:** [정보성 블로그 / 논란형 카드뉴스 / 깃허브 기술 리뷰 등] | **화제성:** [🔥폭발 / 🟡지속 / 🟢미미] |
| **글쓰기 앵글:** [비판적 관점 / 트렌드 전달 / 해결책 제시 등] | **신뢰도:** [공식자료 / 커뮤니티 여론 / 찌라시] |

<br/>

### 1. 📝 콘텐츠 빌딩 블록 (글쓰기 재료)
* **📰 도입부 (핵심 팩트):** 
  * [기사, 공식 발표 등 글을 시작하기 좋은 팩트 1~2줄]
* **🗣️ 스토리텔링 (대중의 반응):** 
  * [커뮤니티, SNS 등에서 사람들이 공감하거나 분노하는 포인트. 글의 몰입도를 높이는 용도]
* **💡 차별화 인사이트 (결론부):**
  * [단순 정보 전달을 넘어, 이 콘텐츠만이 줄 수 있는 '숨겨진 맥락'이나 '통찰력']

### 2. 🔗 레퍼런스 소스 (원문 및 코드)
* **💻 깃허브 / 오픈소스:** [글에 포함할 만한 관련 GitHub 리포지토리 링크 및 짧은 설명 (없으면 생략)]
* **📰 기사 / 커뮤니티:** [소스 링크 1](#) | [소스 링크 2](#)
* **💬 킬러 인용구:** _"[카드뉴스나 글의 인용 블록에 그대로 박아넣기 좋은 명문장 발췌]"_

### 3. ⚡ 콘텐츠 발행 자동화 연계
- [ ] **에이전트 인풋:** 본 리서치 카드를 바탕으로 [플랫폼: 워드프레스/인스타]용 초안 생성 파이프라인 트리거
- [ ] **자동화 연계 툴:** (리서치 중 발견된 관련 툴이 있다면) [ex: HWP 파이썬 패키지, 크롤링 라이브러리 등 제안]
```
