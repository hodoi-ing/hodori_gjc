# 🐯 도리보고 3.0: SNS 카드뉴스 규격 포맷 (6-Slide Slot Format)

> **[🚨 필수 전제 조건: IM_NOT_AI.md 강제 적용]**
> 본 리서치 카드를 작성하는 모든 AI 에이전트는 작성 전 반드시 최상위 경로의 `IM_NOT_AI.md`를 최우선으로 숙지하고 적용한다.
> "결론적으로", "현대 디지털 시대에" 같은 기계적인 번역투나 정형화된 앵무새 요약을 **엄격히 금지**하며, 실제 테크/인사이트 전문 크리에이터가 쓴 것처럼 리듬감(Burstiness) 있고 단도직입적인 '인간형 문장'으로만 출력하라.

## 📱 SNS 카드뉴스 6장 슬라이드 규격 (Slide-by-Slide Rules)

인스타그램, 스레드(Threads), 링크드인 등 SNS 카드뉴스는 줄글 마크다운이 아닌 **장당 1개 메시지(Slide-by-Slide)**로 철저히 제한된 슬롯 구조를 따른다.

| 슬라이드 | 역할 | 글자 수 제한 | 필수 포함 요소 |
| :--- | :--- | :--- | :--- |
| **1장 [표지/훅]** | 어그로 & 시선 고정 | 40자 이내 | 질문 던지기 / 충격적인 전후 비교 / 3초 컷 메인 카피 |
| **2장 [사건 발단]** | 팩트 풀이 (초보용) | 80자 이내 | 발생 일시, 주요 언론 출처, 무슨 일이 터졌는지 쉬운 2줄 요약 |
| **3장 [핵심 포인트]** | 핵심 변화 & 수치 | 100자 이내 | 기존 방식 vs 이번 변화점, 내 지갑/업무에 미치는 영향 |
| **4장 [현장 반응]** | 커뮤니티 찐 여론 | 80자 이내 | 커뮤니티/개발자/대중의 날것 인용구 2개 (🟢 호평 vs 🔴 우려) |
| **5장 [호도리 시선]** | 인사이트 & 행동 가이드 | 80자 이내 | 전문가적 통찰 + "우리는 지금 뭘 해야 하나?" 명확한 행동 지침 |
| **6장 [출처 & CTA]** | 링크 & 공유 유도 | 40자 이내 | 팩트 체크용 원문 링크 + 저장/공유 유도 |

## 📋 표준 출력 템플릿 (Markdown & ASCII Box)

```text
┌────────────────────────────────────────────────────────┐
│ 1장 [표지/어그로 훅]                                   │
│ 🚨 {주제} 지금 난리 난 이유 3초 요약                   │
│ "{핵심 헤드라인/도발적 카피}"                          │
├────────────────────────────────────────────────────────┤
│ 2장 [사건 발단/팩트]                                   │
│ 📌 {발생일시} | {출처}                                 │
│ • 핵심: {사건 팩트 1줄 요약}                           │
│ • 신호: 관련 보도/여론 {언급수}건 실시간 급증          │
├────────────────────────────────────────────────────────┤
│ 3장 [핵심 포인트/비교]                                 │
│ 💡 뭐가 바뀌었나? (놓치면 손해인 부분)                 │
│ • 기존: {이전 상태/상식}                               │
│ • 현재: {이번에 바뀐 변화점/수치/혜택}                 │
├────────────────────────────────────────────────────────┤
│ 4장 [현장 찐 반응]                                     │
│ 🗣️ 실시간 커뮤니티 날것 여론:                          │
│ 🟢 "{실제 호평/기대 인용구}"                           │
│ 🔴 "{실제 비판/우려/주의 인용구}"                      │
├────────────────────────────────────────────────────────┤
│ 5장 [호도리 1줄 가이드]                                │
│ 🐯 "{남들 뒷북칠 때 챙겨야 할 실질적 행동 지침}"      │
├────────────────────────────────────────────────────────┤
│ 6장 [출처 링크 & CTA]                                  │
│ 🔗 원문: {URL}                                         │
│ 💾 도움 됐다면 [저장 💾] & [공유 🚀]                   │
└────────────────────────────────────────────────────────┘
```

## 🎯 랭킹 및 이슈 수량 규칙
1. **최대 6개 (TOP 1 ~ TOP 6):** 핫이슈는 화제성(`hot_score` = 언급량 + 최신성) 순으로 최대 6개까지 정렬.
2. **0~6개 가변 추출:** 억지로 6개를 채우지 않으며, 유의미한 이슈가 2개면 2개만, 0개면 평온 상태 안내 메시지만 출력.
