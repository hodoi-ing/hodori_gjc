# 🐯 도리보고 2.0: 콘텐츠 자동화 리서치 포맷 (Content Research Card)

> **[AI 프롬프트 지침: 톤앤매너 및 철학]**
> 1. **속도와 트렌드:** 메이저 기사보다 한발 앞선 '최근 발생한 커뮤니티/개발자 씬의 핫이슈'를 우선적으로 포착할 것.
> 2. **초보자 + 전문가 동시 만족:** 도입부와 스토리텔링은 **쌩초보도 단번에 이해하고 흥미를 느낄 만큼 쉽고 매력적으로**, 차별화 인사이트와 레퍼런스는 **전문가가 감탄할 만큼 깊이 있고 예리하게(개발적/비즈니스적 통찰)** 작성할 것.

---

## 📋 출력 템플릿

```markdown
# 📡 [리서치 주제] 타이틀 (글의 가제가 될 수 있는 매력적인 제목)

> 💡 **핵심 훅 (The Hook)**
> [쌩초보의 시선을 확 끌 수 있는 한 줄 요약 / 카드뉴스 1장짜리 메인 카피]

| 🎯 콘텐츠 방향성 | 📊 트렌드 신선도 (AI 판단) |
| :--- | :--- |
| **추천 포맷:** [정보성 블로그 / 논란형 카드뉴스 / 기술 리뷰 등] | **발생시점:** [🔥방금 터짐 / 🟡확산 중 / 📉이미 기사화됨] |
| **글쓰기 앵글:** [비판적 관점 / 트렌드 전달 / 해결책 제시 등] | **신뢰도:** [공식자료 / 커뮤니티 여론 / 찌라시] |

<br/>

### 1. 📝 콘텐츠 빌딩 블록 (글쓰기 재료)
* **📰 도입부 (초보자용 팩트 풀이):** 
  * [전문 용어를 배제하고, 사건의 발단과 팩트를 누구나 이해하기 쉽게 1~2줄 설명]
* **🗣️ 스토리텔링 (대중의 반응):** 
  * [커뮤니티, SNS 등에서 사람들이 왜 열광/분노하는지 감정선과 반응 포인트 포착]
* **💡 차별화 인사이트 (전문가용 통찰):**
  * [표면적 현상 뒤에 숨겨진 비즈니스적 의도, 기술적 한계, 혹은 향후 시장 패러다임 변화 등 전문가가 감탄할 딥다이브 인사이트]

### 2. 🔗 레퍼런스 소스 (원문 및 코드)
* **💻 깃허브 / 기술 문서:** [글에 깊이를 더해줄 GitHub 리포지토리나 공식 Docs 링크 (전문가 타겟)]
* **📰 대중 반응 / 기사:** [소스 링크 1](#) | [소스 링크 2](#)
* **💬 킬러 인용구:** _"[카드뉴스나 글의 인용 블록에 그대로 박아넣기 좋은 뼈때리는 명문장 발췌]"_

### 3. ⚡ 콘텐츠 발행 자동화 연계
- [ ] **에이전트 인풋:** 본 리서치 카드를 바탕으로 [워드프레스/인스타]용 초안 생성 파이프라인 트리거
- [ ] **자동화 연계 툴:** [이슈와 관련된 최신 오픈소스 라이브러리나 적용해볼 만한 툴 제안]
```
