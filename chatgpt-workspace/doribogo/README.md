# 🛰️ 도리보고 (Doribogo) `v3.0.0`

> 요리보고 저리보고, **도리보고!**  
> **현재 버전:** `v3.0.0` (Universal Multi-Domain Signal Harvester & SNS 6-Slide Card News Engine)

어떤 주제든(주식, 특가할인, 정치, 경제, IT/AI 등) 실시간으로 무슨 일이 벌어지고 있는지 인터넷 곳곳의 시그널을 찾아내고, **가장 뜨거운 핫이슈(TOP 1~6)**를 SNS(스레드/인스타그램)에 바로 올릴 수 있는 **6장 슬라이드 카드뉴스 포맷**으로 가공해 주는 리서치 엔진이다.

단순한 뉴스 요약기가 아니다.

**주제 안에서 실시간으로 실제로 벌어진 사건·논쟁·변화점의 신호를 포착하고, SNS 독자의 시선을 3초 만에 사로잡는 콘텐츠로 직결시키는 것**이 핵심이다.

## 🚀 빠른 실행 (CLI)

```bash
# 1. 주식/경제 분야 핫이슈 6장 카드뉴스 생성
python chatgpt-workspace/doribogo/universal_harvester.py "금융투자소득세"

# 2. 할인/특가 분야 핫이슈 생성
python chatgpt-workspace/doribogo/universal_harvester.py "아이폰 16 할인"

# 3. 테크/기업 핫이슈 생성 (JSON 출력)
python chatgpt-workspace/doribogo/universal_harvester.py "엔비디아" --json

# 4. GJC 스킬 호출
/skill:doribogo 테슬라
```

## 🎯 핫이슈 선별 및 랭킹 규칙

1. **최대 6개 (TOP 1 ~ TOP 6) 정렬**:
   * **클러스터 강도**: 여러 언론사/커뮤니티에서 동시 보도된 횟수 (가중치 2.0).
   * **최신성(Recency)**: 최근 1~6시간 이내 터진 속보일수록 신선도 보너스 부여.
2. **0~6개 가변 추출 (억지 채우기 없음)**:
   * 유의미한 이슈가 2개면 [TOP 1], [TOP 2]만 출력.
   * 최근 24~48시간 내 유의미한 이슈가 없으면 평온 안내 메시지만 출력.
