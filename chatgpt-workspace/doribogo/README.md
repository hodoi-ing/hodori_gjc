# 🛰️ 도리보고 (Doribogo) `v3.5.0`

> 요리보고 저리보고, **도리보고!**  
> **현재 버전:** `v3.5.0` (5-Radar Multi-Angle Harvester & Insane-Search WAF Penetration Engine)

어떤 단어 하나(주식, 특가할인, 정치, 경제, IT, 브랜드명 등)만 던지면 **5대 다각도 레이더(공식 SNS · 특가 · 게릴라 · 스펙 · 여론)**가 동시에 가동되어 실시간 핫이슈를 낚아채고, SNS(스레드/인스타그램)에 즉시 올릴 수 있는 **6장 슬라이드 카드뉴스**로 뽑아내는 전천후 리서치 엔진입니다.

단순한 뉴스 요약기가 아닙니다.  
**인터넷 곳곳의 초기 변화 시그널과 가격 대란, 게릴라 떡밥을 3초 컷 팩트로 정돈해 콘텐츠로 직결시키는 것**이 핵심입니다.

## 🛰️ 5대 다각도 시그널 매트릭스 (Multi-Angle Sweep)

키워드 하나가 들어오면 단일 검색에 의존하지 않고, **5개 독립 스레드가 동시에 5가지 각도를 정밀 타격**합니다.

```text
                           [키워드 하나 입력]
                                   ↓
        ┌────────────────────────────────────────────────────────┐
        │ 🛰️ 5대 레이더 동시 병렬 가동                          │
        ├────────────────────────────────────────────────────────┤
        │ 📱 1. 브랜드 공식 SNS │ 인스타·X·스레드 공식 공지/티저  │
        │ 💰 2. 가격/특가/대란 │ 역대가, 반값, 0원, 핫딜, 쿠폰   │
        │ ⚡ 3. 게릴라/사건사고 │ 기습 무료, 가격오류, 품절 대란 │
        │ 🛠️ 4. 스펙/출시/패치 │ 신모델, 벤치마크, 아키텍처 비교 │
        │ 🗣️ 5. 커뮤니티 날여론 │ 결함 제보, 찐후기, 고질병, 논란 │
        └──────────────────────────┬─────────────────────────────┘
                                   ↓
        ┌────────────────────────────────────────────────────────┐
        │ 🛡️ insane-search 3단계 WAF 관통 파이프라인             │
        │ 1단계: 크롬 120 브라우저 UA & 모바일 URL 직통 호출     │
        │ 2단계: Cloudflare/403 차단 시 Jina Reader(r.jina.ai)   │
        │        글로벌 프록시로 마크다운 본문 무조건 관통       │
        │ 3단계: 네이버 블로그/뉴스/X 신디케이션 우회 추출       │
        └──────────────────────────┬─────────────────────────────┘
                                   ↓
        ┌────────────────────────────────────────────────────────┐
        │ ⏱️ 최신성 윈도우(when:2d) & TOP 1~6 랭킹 클러스터링     │
        │ • 1~6시간 이내 터진 속보에 초신선도 점수 최우선 부여   │
        │ • 억지 채우기 없이 유의미한 핫이슈만 0~6개 가변 추출   │
        └──────────────────────────┬─────────────────────────────┘
                                   ↓
        📱 SNS(스레드/인스타그램) 6장 슬라이드 카드뉴스 즉시 완성!
```

## 🚀 빠른 실행 (CLI & 스킬)

```bash
# 1. 주식/경제 분야 핫이슈 (TOP 1~6 랭킹)
python3 chatgpt-workspace/doribogo/universal_harvester.py "금융투자소득세"

# 2. 브랜드/제품 할인 및 공식 SNS 피드 탐색
python3 chatgpt-workspace/doribogo/universal_harvester.py "다이슨"

# 3. 테크/오픈소스 게릴라 이슈 탐색
python3 chatgpt-workspace/doribogo/universal_harvester.py "OpenCode Go"

# 4. JSON 원본 데이터 추출
python3 chatgpt-workspace/doribogo/universal_harvester.py "엔비디아" --json

# 5. omp / GJC 스킬 호출
/doribogo 아이폰 16 할인
```

├────────────────────────────────────────────────────────┤

│ • 팩트: {사건 팩트 1줄 요약}                           │
